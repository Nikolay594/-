# Курсовой проект

## Реализация программы контроля облачной инфраструктуры

### 1. Назначение программы

Программа предназначена для анализа телеметрических данных компонентов облачной инфраструктуры.

Программа должна считывать последовательность измерений, анализировать изменение значений компонентов, определять их состояние и обнаруживать инциденты по заданному условию.

Проект разрабатывается на языке C.

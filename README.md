# Курсовой проект

## Реализация программы контроля облачной инфраструктуры

### 1. Назначение программы

Программа предназначена для анализа телеметрических данных компонентов облачной инфраструктуры.

Программа должна считывать последовательность измерений, анализировать изменение значений компонентов, определять их состояние и обнаруживать инциденты по заданному условию.

Проект разрабатывается на языке C.

---

### 2. Индивидуальный вариант № 17 
Компоненты: API, GPU, WEB 

Порядок записи: Б — значение–время–компонент. Разделитель: запятая. 

Тип последовательности (5): Есть записи с неизвестными кодами 
компонентов; их нужно распознать и пропустить. 

Телеметрия за пять отсчётов — одна строка: 
31.3,2,WEB,43.7,1,API,50.6,4,API,34.5,5,WEB,44.2,2,API,55.2,3,GPU,51.1,5,A
PI,53.8,1,GPU,30.6,3,WEB,78.0,5,XYZ,57.2,2,GPU,51.2,5,GPU,75.0,2,XYZ,53.
2,4,GPU,32.0,1,WEB,35.2,4,WEB,44.7,3,API 

Производный показатель Q: Абсолютное изменение. 

$$Формула: Q[i] = X[i] − X[i−k]; k = 2; L = 1.0; D = 10.$$

Правило состояния компонента — Сравнение с критерием L: 

Q < −L: «СНИЖЕНИЕ»; 

−L ≤ Q ≤ L: «НОРМА»; 

Q > L: «РОСТ». 

Правило инцидента — Хотя бы одна тревога: Инцидент возникает, если 
хотя бы один компонент находится в состоянии «ТРЕВОГА» или 
«АНОМАЛИЯ». 

Структура Incident: 
$$typedef struct { int time; int type; float value; } Incident;$$

Поля: номер отсчёта, тип инцидента, значение показателя. 

Проверь: вручную рассчитай Q для доступных пар, определи состояния 
компонентов и запиши булево выражение инцидента.

### 3. Описание компонентов

| Название | Обозначение |
|---|---|
| `API` | интерфейс программирования приложений |
| `GPU` | графический вычислительный ускоритель |
| `WEB` | веб-сервер |

---

### 4. Формат исходных данных

Каждая запись: `значение,время,компонент`, разделены запятой.

Записи `78.0,5,XYZ` и `75.0,2,XYZ` содержат неизвестный код (XYZ) и исключаются. В итоге получаем таблицу из 5 отсчетов:

| Время | API | GPU | WEB |
|---|---|
| 1 | 43.7 | 53.8 | 32.0 |
| 2 | 44.2 | 57.2 | 31.3 |
| 3 | 44.7 | 55.2 | 30.6 |
| 4 | 50.6 | 53.2 | 35.2 |
| 5 | 51.1 | 51.2 | 34.5 |

---

### 5. Алгоритм работы программы

1. Инициализировать массивы значений для API, GPU, WEB.
2. Запустить цикл по индексам от `k` (2) до `N-1` (4).
3. Для каждого компонента вычислить абсолютное изменение \(Q[i] = X[i] - X[i-k]\).
4. Определить состояние компонента (СНИЖЕНИЕ, НОРМА, РОСТ).
5. Вывести таблицу.

Функции программы: 
* `state_q` — определение состояния компонента по значению Q;
* `state_name` — возврат строкового представления состояния;
* `main` — инициализация данных, цикл расчёта и вывод результатов.
